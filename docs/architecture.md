## 两层自回归

Qwen3-TTS 的生成不是单一 Token 序列：

```text
时间方向：F0 → F1 → F2 → ...
帧内方向：c0 → c1 → ... → c15
```

主 Talker 在每个时间步预测第 0 路 Code，较小的 MTP Code Predictor 在该帧内部补全另外 15 路。完整 16 路 Codec 帧随后进入 Code2Wav。

当前权重的精确时间倍率为 12.5 fps：每帧 1,920 个 24 kHz 采样点，即 80 ms。

## Pro 补丁边界

补丁主要覆盖：

1. WebSocket speech streaming 协议与 Token Plan；
2. 运行中请求的文本 Token 热追加；
3. 输入不足时的调度暂停/恢复；
4. Talker 条件轨和 KV 的连续更新；
5. Talker 到 Code2Wav 的流式 Chunk 传输；
6. Code2Wav 首包、上下文与批处理路径；
7. 对应单元测试。
