# WebUI 与双轨语义

## 布局

WebUI 第一行用于文本、音色、语言和生成控制；第二行“**双轨自回归推理**”完整显示条件与音频时间步。

## 上下双轨

每个推理步占同一列：

```text
TEXT   T0  T1  ...  E   P   P
        │   │        │   │   │
CODEC  F0  F1  ...  Fn  ... ...
```

- `T<n>`：服务端 Token Plan 中的真实 Text Token，悬浮可查看 BPE piece 和 ID；
- `E`：Text EOS；
- `P`：EOS 后模型内部 PAD 条件，不是浏览器继续发送的 Token；
- `F<n>`：完成 Code2Wav 后由 PCM 精确折算的 Codec 时间帧。

一行放不下时整组上下双轨换到下一行，历史不会被滑动窗口裁剪。

## 颜色

- 紫色提交脉冲：新 PCM 包折算出的 Codec 帧进入轨迹；
- 青色：已生成、尚未播放；
- 琥珀色：当前播放帧；
- 当前块内绿色填充：该 80 ms 帧的播放百分比；
- 绿色：已经播放完成。

播放位置读取 Web Audio 的实际时钟。缓冲或排程空隙时，轨迹不会根据“已收到字节数”虚假推进。

## 重要限制

同列只表示模型计算步的条件配对，不代表 Text Token 与具体发音片段存在强制语义对齐。服务返回的是 PCM，不是原始 `[F, 16]` Codec ID；因此 WebUI 能精确显示时间帧和播放进度，但不能展示每帧 16 路真实码本值。
